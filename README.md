# Abd Alazez Rehan | Frontend Developer Portfolio

A modern, minimalist, and fully responsive personal portfolio website engineered with a clean separation of concerns (`HTML5`, `CSS3`, and `Vanilla JavaScript`). Designed to showcase frontend architecture, technical competencies, and featured web applications.

---

## ✨ Key Features

- **Clean Architecture:** Strictly separated into structural markup (`index.html`), design system & layout (`style.css`), and UI behavioral logic (`main.js`).
- **Custom High-Saturation Palette:** Built around a vibrant, cohesive three-color design system derived from:
  - **Soft Lavender White** (`#E9E8F8` base / `#DCD8FA` saturated) — Primary background and elevated card surfaces.
  - **Powder Blue** (`#8DB9F0` base / `#3A86FF` saturated) — Primary actions, interactive states, and key highlights.
  - **Warm Sunset Peach** (`#F5B69E` base / `#FF784F` saturated) — Secondary accents, badges, and directional links.
- **Fully Responsive:** Mobile-first CSS Grid and Flexbox layouts with an interactive mobile navigation drawer.
- **Dynamic Scroll-Spy:** Vanilla JavaScript scroll tracking that automatically updates active navigation states as the user scrolls through sections.

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5

- **Styling:** Modern CSS3 (Custom Properties, Flexbox, CSS Grid, Media Queries)

- **Scripting:** Vanilla JavaScript (ES6+)

- ## **Typography:** Plus Jakarta Sans via Google Fonts
